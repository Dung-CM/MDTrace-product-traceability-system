## 📌 Project Overview
**MDTrace** is a production-ready B2B SaaS supply chain traceability platform designed to bridge the gap between traditional enterprise software (Web2) and the trustless nature of Blockchain (Web3). 

Faced with the real-world challenge of product counterfeiting and data tampering, I architected MDTrace to ensure absolute data integrity while maintaining a frictionless, seamless user experience for traditional businesses.
